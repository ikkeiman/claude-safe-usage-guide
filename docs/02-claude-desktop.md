# 02. Claude Desktop を安全に使う

Claude Desktop で業務に関係するのは、主に **MCP サーバー（ローカルの道具）・拡張機能（`.mcpb`）・コネクタ（リモートの MCP サーバー）** の 3 つです。
どれも「Claude に道具を渡す」仕組みで、渡した道具は**あなたの権限で動きます**。MCP サーバーの作り方の詳細は、姉妹リポジトリ [secure-mcp-server-guide](https://github.com/ikkeiman/secure-mcp-server-guide) にまとめています。

## 押さえておく事実（公式ドキュメントより）

- 設定ファイル `claude_desktop_config.json` に書いたローカル MCP サーバーは、**アプリ起動時に Claude Desktop が子プロセスとして起動**し、標準入出力でやり取りする。サーバーは**利用者のアカウントの権限で動く**（[D1]）
- 「すべての操作は実行前に明示的な承認が必要」とされ、ツールの呼び出しは承認 UI を通る（[D1]）
- 起動したサーバーの stderr は、ログフォルダの `mcp-server-<名前>.log` に保存される（[D2]）
- 拡張機能（MCP Bundle、`.mcpb`）は、`manifest.json` の `user_config` で `"sensitive": true` を付けた値を **OS の安全な保管領域に保存**できる。Team / Enterprise では管理者が拡張機能の許可・ブロックを制御できる（[D3][D4]）
- リモートのコネクタは、公式に「信頼できる組織のサーバーにだけ接続する」「認証時に要求される権限を確認する」「『常に許可』は信頼できるサーバーにだけ使う」と注意されている（[D5]）

| OS | 設定ファイル | ログ |
|---|---|---|
| macOS | `~/Library/Application Support/Claude/claude_desktop_config.json` | `~/Library/Logs/Claude` |
| Windows | `%APPDATA%\Claude\claude_desktop_config.json` | `%APPDATA%\Claude\logs` |

## 入れる前に（1 つの MCP サーバー・拡張機能ごとに）

| # | 確認すること | なぜ |
|---|---|---|
| 1 | **出所**: 公式・自社・信頼できる発行者か。リポジトリとライセンスがあるか | 自分の権限で他人のコードが動く（[01](01-threats.md) X4） |
| 2 | **道具の一覧**: 書き込み・削除・送信・実行の道具を持っていないか。持っているなら本当に必要か | 本文に混ざった指示で悪用されうる（X2, X3） |
| 3 | **触る範囲**: 許可フォルダやアカウントの範囲が必要最小か（ホーム全体を渡していないか） | 被害の範囲を決める |
| 4 | **起動方法**: `npx -y` / `uvx` で毎回取ってくる形なら、版を固定するか、ローカルに置いた固定版を起動する | 起動のたびに中身が変わりうる |
| 5 | **秘密の置き場所**: トークンを `claude_desktop_config.json` の `env` に平文で書いていないか。拡張機能なら `sensitive` で保管されるか | 設定ファイルは平文で残る |
| 6 | **ログ**: サーバーが本文や検索語をログに書かないか | ログが機密の置き場になる（X7） |
| 7 | **第三者の検査**: 公開されている評価（例: MCP の評価サービス）や、読み取り専用の注釈が実装と一致しているか | 説明と実装の食い違いを見つける |

## 使うときに

- **承認のダイアログは毎回読む**。「常に許可」は、自分で中身を確かめた読み取り専用の道具にだけ使う
- **知らない Web ページやメールを読ませた直後**は、書き込み・送信の道具を呼ぼうとしていないかを特に注意して見る
- **個人情報・社外秘はそもそも入力しない**。必要なら伏せた形にしてから使う（[06](06-sensitive-data.md)）
- 道具が想定外の動きをしたら、ログ（`mcp-server-<名前>.log`）を見る。ログに本文が出ていたら、その道具の使い方を見直す

## 組織で使うなら

- 使ってよい拡張機能・コネクタを**許可リスト**にし、管理画面で制御する（Team / Enterprise）
- 自作の道具は「読み取り専用・単機能」から始める（[secure-mcp-server-guide](https://github.com/ikkeiman/secure-mcp-server-guide) の推奨案 A）。書き込みが要る道具は別のサーバーに分ける
- 配布するなら設定ファイルの手編集ではなく `.mcpb` にし、秘密は `sensitive` で保管する
