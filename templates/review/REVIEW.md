# REVIEW.md — このリポジトリのレビュー基準

AI（Claude Code の /code-review、/security-review を含む）と人のレビューで、毎回この基準を見ます。
作業する側（AI）が書き換えないよう、変更は人がレビューして入れます。

## 必ず止めるもの

- 秘密情報（API キー、トークン、パスワード、鍵）がコード・設定・テスト・ログに入っている
- 利用者の入力をエスケープせずに HTML に入れている（`innerHTML` など）
- 外部への送信先が増えている、または送る中身が増えている
- 頼まれていないファイル・機能の変更
- 公式ドキュメントで確かめられない API・関数・設定項目を使っている

## 確かめるもの

- 権限: 誰が実行でき、何に触れるか。最小になっているか
- エラー時: 途中で失敗したら何が残るか（二重登録、半端な状態）
- テスト: 仕様を表しているか。AI が書いたテストを、AI が書いた実装に合わせて直していないか
- 依存: 増えたなら出所・版・ライセンス
- 記録: ログに本文や個人情報を書いていないか
